2. Dados Pessoais Recolhidos

Recolhemos dados pessoais apenas quando necessário para prestar os nossos serviços:

  • Informações de contacto (nome, telefone, e-mail)
  • Dados de agendamento e histórico médico (quando relevante para o tratamento)
  • Informações de pagamento

3. Base Legal

Tratamos os seus dados com base no seu consentimento (artigo 6(1)(a) RGPD) e na execução de contrato para prestação de serviços (artigo 6(1)(b) RGPD).

4. Retenção de Dados

Os dados pessoais são retidos pelo período necessário para prestar os serviços e cumprir obrigações legais, normalmente até 10 anos conforme regulamentação de dados clínicos em Portugal.

5. Direitos dos Titulares

Tem direito a:

  • Acesso aos seus dados pessoais
  • Retificação de dados incorretos
  • Apagamento de dados ("direito ao esquecimento")
  • Limitação do tratamento
  • Portabilidade de dados
  • Oposição ao tratamento

Para exercer qualquer destes direitos, contacte-nos em fisioritaguerreiro@gmail.com ou 961 899 364.

6. Segurança dos Dados

Implementamos medidas técnicas e organizacionais apropriadas para proteger os seus dados contra acesso não autorizado, alteração ou destruição.
