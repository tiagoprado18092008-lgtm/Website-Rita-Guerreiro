Resumo do design

  • Painel esquerdo — 5 categorias com contagem de serviços. Hover muda o painel direito.
  • Painel direito — nome da categoria + descrição curta + lista de serviços em 2 colunas + link "Ver todos".
  • Categorias com página própria (Fisioterapia, Massagens, Holísticas) têm link "Ver todos" que vai para essa página.
  • Mobile — accordion: clica na categoria, expande os serviços.

Este design substitui o mega-menu atual em ui.jsx. Nenhuma página HTML precisa de ser alterada.
